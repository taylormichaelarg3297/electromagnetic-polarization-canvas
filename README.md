## Explore the Visualization

Electromagnetic Wave Polarization Canvas is a web-based scientific tool for studying the motion and orientation of electric-field vectors across multiple polarization states. Its animated 3D isometric display helps make changing field directions easier to inspect for teaching, independent learning, and hands-on conceptual exploration.

This single-page application supports linear, circular, and elliptical polarization. Users can vary the amplitude, angular frequency, and phase difference, allowing wave behavior to be compared visually through interactive controls rather than through fixed illustrations alone.

- Examine linear, circular, and elliptical polarization.

- Modify field magnitude using the amplitude slider.
